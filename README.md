# ValorNook

ValorNook enables Data-Driven decision making through Real-Time data processing and Auto-Scaling API Gateway integrations.

ValorNook is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ValorNook.git`
2. `cd ValorNook`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ValorNook, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
